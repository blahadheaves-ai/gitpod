SECURITY POLICY
---------------
Policy for reporting vulnerabilities and the process for handling security issues.

- Report privately to: <SECURITY_CONTACT_EMAIL>
- We will acknowledge receipt within 72 hours.
- The triage process and timeline (e.g., 90 days to coordinate public disclosure) will follow our security response policy.
- Provide PGP key or preferred secure channel if available.

Automated scans
- We use: `cargo audit`, `cargo-deny`, SCA/SBOM tools, and static analyzers. See RELEASE_CHECKLIST.md for commands.
